# Security policy

## Supported versions

Security fixes are applied to the latest version on the default branch.

## Reporting a vulnerability

Please use GitHub's private vulnerability-reporting feature for this
repository. Do not include secrets, private coordinates, or sensitive datasets
in a public issue.

Include the affected version, operating system, reproduction steps, and the
impact you observed. Maintainers will acknowledge the report and coordinate a
fix and disclosure timeline through the private report.

## Data and network behavior

Coordinate conversion is local. The optional MapView feature connects to the
NGMDB website and requires internet access. Review data before opening it in an
external map service when location confidentiality matters.
